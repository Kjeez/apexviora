# APEXVIORA — Next.js Landing Page

A clean, responsive recreation of the supplied APEXVIORA wooden-packaging homepage reference.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Images

All image areas are intentionally blank placeholders. Replace the `.blank-image` blocks in `app/page.js` with `<Image />` components or background images when your final photography is ready.

The India locations section also uses a CSS placeholder shape so the layout remains complete without an image asset.

## Main files

- `app/page.js` — complete page structure and content
- `app/globals.css` — responsive styling and design system
- `app/layout.js` — metadata and global layout
- `package.json` — Next.js dependencies/scripts
